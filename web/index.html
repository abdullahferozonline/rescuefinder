Before you go offline

  • Install/open RescueFinder while you still have internet.
  • Grant location permission and test GPS outdoors.
  • Download a map package for the area and check it opens offline.
  • Tell a trusted person your route and expected return time.
  • In an emergency, use the local emergency number if a call is possible. In India, 112 is the pan-India emergency number.
